# Time Machine

An interactive time-travel themed web application built using HTML, CSS, and JavaScript.

## Features

- Interactive time-machine interface
- User input
- Time and duration selection
- Travel screen
- Summary screen
- Success and error screens
- Smooth page transitions
- Interactive button effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
